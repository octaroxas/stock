  • Quem recebe é sempre um servidor com login? Se não, a assinatura eletrônica não cobre todos os casos.

Notas de implementação

  • O PDF usa uma view Blade própria, com tabelas e CSS simples. O DomPDF não suporta flex nem grid.
  • Cabeçalho, logo, rodapé e numeração vêm da configuração do município.
  • O termo de responsabilidade só é emitido quando há bem permanente na entrega.
  • Entrega parcial gera o termo só do que saiu e deixa o restante pendente.
